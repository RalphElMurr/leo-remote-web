# Leo Remote web

Phone remote for the Leo Remote car app.

- **Bluetooth LE:** open this page in Bluefy (iPhone) or Chrome (Android).
- **Wi-Fi:** with your phone on the same Wi-Fi as the car, type the car's address in the "Over Wi-Fi" box.
  That opens the same page served by the car itself (`http://CAR_IP:8686/`), which works in plain Safari.

Add `?demo` to try it with a simulated car. The PIN is stored only on your phone.
